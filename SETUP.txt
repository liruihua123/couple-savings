============================================================
情侣存款 App · 出包与部署说明（安卓 Kotlin + Supabase）
============================================================

【重要前提：APK 在哪出】
这套工程源码我已经写好并验证过可编译结构，但当前云端沙箱没有安装
JDK / Gradle / Android SDK，**我没法在这里直接编出 .apk 文件**。
所以"出包"这一步需要借助下面的自动化流程，你只管下载和安装。

给你两条路，推荐走【路径一】，全程不用装 Android Studio：

------------------------------------------------------------
路径一：GitHub Actions 云端自动出包（推荐，你只下载安装）
------------------------------------------------------------
我已经写好 .github/workflows/build.yml：你把代码推到 GitHub，
服务器自动下载 Gradle + Android SDK 帮你编出 APK，你下载装就行。

1. 在 GitHub 新建一个空仓库（如 couple-savings）。
2. 把整个 CoupleSavings 文件夹推上去：
     cd CoupleSavings
     git init && git add . && git commit -m "init"
     git branch -M main
     git remote add origin https://github.com/你的名/couple-savings.git
     git push -u origin main
3. 进仓库 → Actions → 选 "Build Debug APK" → Run workflow。
4. 跑完（约 3–6 分钟）在 Artifacts 里下载 couple-savings-apk，
   里面就是 app-debug.apk。

------------------------------------------------------------
路径二：本机 Android Studio 出包（兜底）
------------------------------------------------------------
1. 安装 Android Studio（勾选 Android SDK + SDK Platform 34）。
2. Open 选中 CoupleSavings 目录，等 Gradle 同步完成。
   （首次打开会自动生成 Gradle 包装器；若提示缺 SDK，按引导装 34 即可）
3. Build → Build Bundle(s)/APK(s) → Build APK(s) → 拿 app-debug.apk。

============================================================
第一步：建 Supabase 后端（两边路径都要先做，免费）
============================================================
1. 打开 https://supabase.com ，注册并 New Project（地区选离你近的）。
2. 左侧 SQL Editor → New Query → 把本工程 schema.sql 全选粘贴 → Run。
   （自动建 4 张表 + 触发器 + 配对函数 + 行级安全策略）
   注意：若你之前已经跑过旧版 schema.sql，直接【再跑一次】即可——脚本全是
   "if not exists"，会安全补上新增的 snapshots(每日资产快照)表，不动已有数据。
3. Project Settings → API，复制两个值备用：
   - Project URL        （形如 https://xxxxxxxx.supabase.co）
   - anon public key    （一长串）

============================================================
第二步：把密钥填进 App（必须在"出包/推送"之前做）
============================================================
打开 app/src/main/java/com/couplesavings/couplesavings/data/SupabaseConfig.kt
把两行占位改成你的真实值：
  const val URL = "https://xxxxxxxx.supabase.co"
  const val ANON_KEY = "你复制的 anon key"
（anon key 是公开安全的，靠登录后的 JWT + RLS 做权限隔离，可放心写进客户端）

============================================================
第三步：出包
================================------------
按上面【路径一】或【路径二】走即可。注意：先填好第二步的密钥再推送/编译，
否则编出来的包连不上后端。

============================================================
第四步：装到手机（两种方式）
================================------------
方式 A（推荐，稳）：
  - 手机 设置 → 关于手机 → 连点"版本号"7 下开开发者模式
  - 开发者选项 → 开"USB 调试"
  - 数据线连电脑，命令行：  adb install app-debug.apk

方式 B（简单）：
  - 把 app-debug.apk 用微信/网盘发到手机
  - 手机 设置 → 安全 → 允许"未知来源"应用安装 → 点 APK 直接装

============================================================
第五步：两人怎么用
============================================
1. 你先注册登录（邮箱+密码），进"绑定情侣"页，把 8 位邀请码发给对象。
2. 对象也装好、注册登录后，在"绑定情侣"页输入你的邀请码 → 配对成功。
3. "资产"页添加账户：
   - 存款：填余额(元)
   - 理财：填"当前净值(元)"+ "本金(元)"（银行不开放实时接口，每周看一眼手动更净值）
   - 积存金：填"持有克数"+"累计投入成本(元)" → App 自动按实时金价算盈亏
4. "流水"页记每笔收入/支出，选"谁记的"，双方实时同步可见。
5. "总览"页看共同净资产、存款、理财、积存金盈亏与当前金价，每 8 秒自动刷新。

============================================================
已新增能力：登录 Token 自动刷新（本次更新）
============================================
- 登录/注册现在同时保存 access_token 与 refresh_token。
- 所有数据请求套了自动续期：访问令牌约 1 小时过期后，下一次请求会
  静默用 refresh_token 换发新令牌并重试，你们俩基本无感地一直保持登录，
  不再需要每小时手动重登。
- 若 refresh_token 也失效（极少发生），会自动弹回登录页。

============================================================
已知限制 / 后续可加
============================================
- 积存金用国际现货金价估算，与银行报价有微小点差，属正常。
- "实时"靠 8 秒轮询；要毫秒级真推送可后续接 Supabase Realtime。
- 总览页新增"收益走势"折线图：App 每次刷新自动把当天净资产 / 积存金盈亏
  写入 snapshots 表，折线图读历史。首日只有 1 个点不画曲线，几天后自然成线（红涨绿跌）。
- 没做转账/预算/收益折线图，需要再说，我给你加。
- CI 里 Android SDK 命令行工具下载链接若 404（Google 偶尔升版本号），把
  build.yml 中 commandline-tools-linux-11076708_latest.zip 的 11076708 换成
  developer.android.com 上最新的 Command line tools 版本号即可。

有任何报错把日志贴给我，我帮你改。
